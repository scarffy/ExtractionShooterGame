# Extraction Shooter

Delta Force-style extraction shooter prototype. Unity 6000.3.15f1 (URP) + FishNet, server authoritative.

**Features:** hideout with stash, trader and squads · PvP matchmaking into raids (squads up to 4, 12 players) ·
Tetris-style grid inventory with pockets, a safe box kept on death and a knife that's never lost · 14 weapons,
32 ammo types, 8 attachments · recoil patterns and bullet drop · aim-down-sights, sprint, crouch, knife ·
bleeding, fractures and timed treatment · frag, smoke and flash grenades · armor with penetration and wear ·
bots that take cover, flank and hear gunshots · compass, map and tactical panel · procedural audio ·
a 160 m raid map (compound, hangar, village, vault loot room) with free, paid and late-raid exits ·
carried weight (e.g. 27.8 / 70 kg) that slows you when heavy · end-of-raid summary (kills, value in and out, profit) ·
private containers (only the owner or current looter receives contents) · primitive humanoid characters with
worn gear and a first-person viewmodel.

Open the project in Unity 6000.3, open `Assets/_Game/Scenes/Sandbox.unity` and press Play, then Host.
See [Assets/_Game/README.md](Assets/_Game/README.md) for the full design, controls and code layout.
